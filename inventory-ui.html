Pet / Item Inventory System

Cartoony Style Inventory System Pet System Simulator UI Vector Art

A vibrant cartoon simulator inventory modal built for high-retention pet collecting experiences. Combines 3D comic header typography, high-tactile action pill buttons, and a clean 10-slot responsive item grid.

Design highlights

  • Custom comic 3D header banner with cyan carbon pattern and bold drop-shadow typography
  • Tactile action pill toolbar with dedicated Search input, Equip Best, Delete Mode, and Filter actions
  • 10-slot item grid featuring gold legendary and green uncommon rarity card frames
  • Clear item level badges and custom pet vector artwork designed to maintain contrast on small screens
  • Chunky red comic close button with intuitive touch sizing for mobile players

Luau implementation ready

  • UIGridLayout with UIAspectRatioConstraints so pet cards maintain perfect square proportions across all resolutions
  • Equip Best and Delete Mode toggle states prepared for simple boolean attribute binding
  • Search bar input pre-configured with TextChanged debouncing logic in mind
