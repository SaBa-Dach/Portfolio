Player Trading: Counter-Offer Negotiation

Dark Style Trading System Counter Offer RAP / Value Modular Grids

A clean Roblox trading interface designed for high-value player exchanges. Features side-by-side OLD vs NEW negotiation states so players can clearly compare counter offers with live Value and RAP metrics.

Design highlights

  • Dual tier comparison: side-by-side OLD and NEW trade slots so players immediately spot incoming counter-offer edits
  • Live RAP and Value header metrics calculated and displayed for both sides of the trade
  • Modular 4-slot grid layout optimized for simulators and high-tier item economies
  • Status feedback banner with high-contrast neon green accepted state to prevent trade confusion
  • High contrast dark theme built with 9-slice rounded corners, subtle slot transparencies, and clean framing

Luau implementation ready

  • Built with UIAspectRatioConstraint and AnchorPoint 0.5/0.5 for perfect scaling across PC, tablet, and mobile
  • Modular item slot frames designed for automated script templating and inventory binding
  • Optimized CanvasGroup hierarchy for clean spring pop-in and dismissal animations via TweenService
